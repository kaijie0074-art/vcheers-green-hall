# V cheers 绿厅预约正式接入清单

## 1. 当前原型验证范围

当前工程只验证一个绿厅、一个共享座位池的预约闭环：

1. 用户模拟微信登录，首次将微信身份与后台会员名册绑定。
2. 管理员通过固定 CSV 模板新增或更新会员名册，绑定关系不会被导入覆盖。
3. 用户查看今天起 7 天内的每小时余量并预约 1–4 小时连续时段。
4. 用户在预约开始前取消，全部覆盖时段立即释放名额。
5. 管理员设置每日容量、管理预约状态并审计敏感信息查看。
6. 管理员补记当天或历史预约的到场情况，撤销误标，或填写原因取消未到场记录。
7. 按预约日期下载 Excel：VC-ID、姓名、手机号、预约日期、预约时长、是否到场。每笔预约一行，含已取消记录；到场字段为“是 / 否 / 已取消”，时长为数值小时，编号和手机号为文本。

## 2. 正式系统最低能力

### 2.1 身份与权限

- 微信登录换取稳定的内部用户 ID，不能信任客户端传入的用户身份。
- 用户只能读取和取消自己的预约。
- 容量设置、全量记录、完整手机号和状态管理只对管理员开放。
- 管理员每次查看完整手机号都记录操作者、预约、时间与来源。

### 2.2 建议接口

| 方法与路径 | 用途 |
|---|---|
| `POST /auth/wechat/login` | 用微信临时 code 换取系统登录令牌 |
| `POST /me/member-binding` | 校验并绑定已导入的会员编号 |
| `POST /admin/member-imports/preview` | 解析并整批校验会员名册 |
| `POST /admin/member-imports/:id/confirm` | 确认写入会员名册 |
| `GET /admin/members` | 查看会员资料、状态与绑定关系 |
| `GET /spaces/green-hall/availability?from=&to=` | 获取日期、小时容量与剩余数 |
| `POST /reservations` | 原子校验连续时段并创建预约，接受幂等键 |
| `GET /me/reservations` | 查询当前用户预约 |
| `POST /reservations/:id/cancel` | 用户幂等取消自己的未开始预约 |
| `GET /admin/reservations?date=` | 管理员查询指定日期全部记录 |
| `GET /admin/reservations/export?date=` | 按预约日期导出六列 Excel，验证管理员权限并记录导出行为 |
| `PUT /admin/capacities/:date` | 设置今天起 7 天内的每日容量 |
| `POST /admin/reservations/:id/actions` | 到场、撤销到场、取消或恢复 |
| `POST /admin/reservations/:id/phone-reveal` | 返回完整手机号并写入审计 |

### 2.3 数据与并发约束

- `User` 保存微信身份与角色；`Member` 保存唯一会员编号、姓名、手机号、状态和绑定用户。
- VC-ID 固定为 6 位数字字符串，数据库、导入、绑定、预约快照和导出均保留前导零，不使用数值类型存储编号。
- 一个有效会员编号最多绑定一个微信用户，一个微信用户最多绑定一个有效会员编号。
- `Reservation` 保存用户、会员编号快照、空间、日期、时段、状态、联系信息快照、幂等键和操作时间。
- `DailyCapacity(spaceId, date)` 唯一；未设置时使用默认容量。
- 创建、恢复、取消和容量调整必须在服务端事务或等价原子机制中完成。
- 创建或恢复时，连续覆盖的每一个小时都必须仍有余量。
- 同一用户在同一天的有效预约不能时间重叠，相邻时段允许。
- 容量不得低于当天任一小时的有效预约峰值。
- 状态变化和敏感信息查看都要留下不可由客户端修改的审计记录。
- 管理员可补记当天及历史预约的到场和撤销误标，不允许提前标记未来日期到场；管理员取消未到场记录不限于预约开始前。用户自行取消和恢复预约仍执行原有开始前限制。
- 业务时间统一按 `Asia/Shanghai` 解释；数据库时间建议保存为 UTC。

## 3. 上线前确认项

1. 确认微信小程序 AppID、主体、登录方式和管理员名单来源。
2. 确认使用微信云开发还是独立后端，并建立测试与生产环境。
3. 确认真实手机号和会员编号是否都为必要字段，并补充隐私政策、保存期限和删除机制。
4. 接入服务端并完成多人同时抢最后名额的并发测试。
5. 完成用户取消、管理员误操作恢复、营业时间跨日边界和时钟偏差测试。
6. 配置操作日志、异常告警、数据备份与管理员权限回收流程。

在服务端身份、权限和原子容量校验完成前，本工程只能用于演示和需求验证，不能直接上线收集真实数据。
