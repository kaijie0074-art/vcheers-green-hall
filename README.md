# V cheers 绿厅预约 MVP

这是一个可运行的 Web 交互原型，用来验证绿厅共享座位预约的最小闭环：

> 微信登录 → 首次绑定后台名册中的会员编号 → 用户预约或取消 → 管理员维护名册、容量和预约状态

预约对象固定为一个共享座位池，不选择具体座位。营业时间为 13:00–22:00，按整点起约，单次 1–4 小时，用户可预约今天起 7 天内的时段。

## 本地运行

```bash
pnpm install
pnpm dev
```

浏览器打开终端显示的地址。顶部提供两个演示入口：

- `/member`：模拟微信登录，首次绑定会员编号，预约并管理自己的记录。
- `/admin`：独立管理员登录，导入会员名册、设置容量并管理预约状态。

用户端演示绑定资料：会员编号 `VC2026090301`，手机号后四位 `8001`。管理端可下载固定 CSV 模板，Excel 名册另存为 UTF-8 CSV 后即可导入。

演示数据与操作结果仅保存在当前浏览器标签页的 `sessionStorage`。点击顶部“重置数据”可恢复初始状态。原型使用虚构资料，请勿录入真实个人信息。

## 验证

```bash
pnpm build
pnpm test
pnpm test:e2e
```

- 领域测试覆盖会员绑定、名册导入、连续时段容量、重叠校验、幂等提交、取消释放、到场窗口和操作审计。
- 浏览器测试覆盖登录绑定、桌面及移动端预约闭环、管理端名册导入、容量与状态操作、页面溢出和关键字号。

## 当前边界

- 当前是 React Web 原型，不是微信原生小程序工程。
- 当前微信登录和管理员登录均为交互模拟，没有接入 AppID；`/admin` 路由不等于真实权限控制。
- `sessionStorage` 无法提供生产级并发控制。正式版必须由服务端事务或原子操作防止超卖。
- 首版不包含具体座位选择、活动导入、人工审核、候补、支付、二维码、消息通知、会员积分或多空间管理。
